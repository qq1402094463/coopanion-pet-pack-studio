# 制作流程总览

七个阶段。每个阶段都有产出和验收标准。
没通过验收不要进下一阶段，否则错误会叠加。

```
阶段 0  准备         5 分钟
阶段 1  定形象       30 分钟到 3 小时，取决于素材
阶段 2  建项目       5 分钟
阶段 3  表情图       0 到 2 小时，可选
阶段 4  清单与词表   10 分钟
阶段 5  校验         2 分钟
阶段 6  打包导入测试 10 分钟
阶段 7  迭代修复     反复
```

---

## 阶段 0 · 准备

### 要做的事

**1. 确认 Coopanion 装在哪。**

你机器上是：

```
程序：D:\AIGJ\Coopanion\Coopanion.exe
数据：D:\AIGJ\Coopanion\data\
源码参考：D:\AIGJ\Coopanion\resources\app\node_modules\cortico-world-desktop-pet\
```

换机器或重装后，读 `C:\Users\<你>\AppData\Local\Coopanion\data-location.json`
就知道新的位置。

**2. 确认工具能跑。**

双击 `studio\启动工具.bat`。
黑窗口里打出 `http://127.0.0.1:8848/` 这类地址就算通过。
8848 被占用时它会自动换成 8849、8850，认黑窗口里那个地址。

需要 Python 3.10 以上。你这台是 3.13，没问题。
`node` 和 `ffmpeg` 都是可选的：

| 工具 | 没有会怎样 |
|---|---|
| Python | 工具根本起不来，必须先装 |
| Node | 少一层加载测试，只能查格式，查不出代码问题 |
| ffmpeg | 不能给视频抽帧，其他功能照用 |
| Pillow | 「设为主图」直接把原图复制过去，不帮忙居中和缩放 |

Pillow 装不装都行。装了效果更省心：

```
pip install pillow
```

### 验收

- 工具页面能打开。
- 页面顶部「接口已配置」或「接口未配置」正常显示。

## 阶段 1 · 定形象

这是最花时间的一步，也是最决定成败的一步。

### 要做的事

拿到一张**透明背景 PNG**。

| 项 | 要求 | 为什么 |
|---|---|---|
| 背景 | 完全透明 | 不透明就是桌面上一块白板 |
| 脚底 | 贴图片底边 | 程序按底边对齐地面，脚悬空会飘 |
| 比例 | 方图最好，宽高比不超过 1:1.6 | 超了会被等比缩小，宠物变很小 |
| 长边 | 512 到 1024 | 再大程序里也只画 256 |
| 主体位置 | 水平居中，垂直偏下 | 上方要留给气泡和特效 |
| 边缘 | 不要白边毛边 | 缩小后白边会变成一圈脏线 |

### 三条路，按方便程度排

**路 A：已经有图。** 直接用。检查上面那张表就行。

**路 B：让 AI 画。** 提示词在 `04-AI提示词-备用平台.md` 的「画主图」一节。
要点是必须说清"透明背景""正面站立""脚底贴边""纯白背景方便抠图"。

**路 C：用现有照片。** 最难。照片抠图后再调姿态，通常效果不好。
除非原图就是白底正面全身照，否则不建议。

### 产出

一张 `xxx.png`，放在手边，下一步要拖进工具。

### 验收

用系统自带的照片查看器打开，确认：

- 背景是格子（透明），不是白色。
- 整只宠物完整，没有裁掉耳朵或脚。
- 缩到 200 像素看清不清。看不清就重画。

## 阶段 2 · 建项目

### 要做的事

1. 打开工具。
2. 左边填 id 和显示名字。
3. 点「＋ 新建项目」。
4. 把阶段 1 的 PNG 拖进虚线框。
5. 在缩略图上点「设为主图」。

### id 怎么起

`id` 是形象包的唯一标识，导入后不能和别的包重名。

| 规则 | 例子 |
|---|---|
| 只能小写字母、数字、横杠 | `blue-cat` ✅ `BlueCat` ❌ `blue_cat` ❌ |
| 1 到 32 位 | |
| 首字符不能是横杠 | |
| 不能叫 `coo` | 那是内置形象 |

建议用英文或拼音。中文 id 直接不合格。

### 工具这时候做了什么

```
projects\<id>\
  project.json         记录创建时间和主图来源
  raw\                 你上传的原图
  pack\                真正要导入的包
    figure.json        ← 会被改
    figure.js          ← 不动
    thumb.png          自动生成
    tex\body.png       主图
    tex\face-*.png     模板自带的三张示例表情
```

### 验收

- 项目出现在左边列表。
- 缩略图能看到你的宠物。
- 点「检查这一包」，红色为 0。

## 阶段 3 · 表情图（可选）

不做也能用。做了才有表情差别。

### 为什么模板自带三张要先删掉

模板里带了 `face-happy.png` `face-love.png` `face-sleepy.png`。
它们画的是模板那只蓝色小生物，不是你的宠物。

如果留着，你的宠物开心时会突然变成蓝色小生物。

**换主图之后，一定要处理这三张：**

- 删掉它们 → 表情全部退回主图，统一但不出戏。
- 或者覆盖成你自己的 → 表情有变化。

工具目前没有删图按钮。
去 `projects\<id>\pack\tex\` 手动删，或者覆盖。

### 要做的话，做几张

按性价比排：

| 优先级 | 文件名 | 什么时候用得上 |
|---|---|---|
| 1 | `face-happy.png` | 最高频。AI 夸它、你摸它都会用 |
| 2 | `face-love.png` | 第二高频。带爱心粒子 |
| 3 | `face-sleepy.png` | 挂机久了会用 |
| 4 | `face-surprised.png` | 被突然拖动时 |
| 5 | `face-cry.png` | 被欺负时 |
| 6 | `face-angry.png` | 生气时 |
| 7 | `face-shy.png` `face-smug.png` `face-pout.png` | 性格细节 |

### 怎么做

**最省事：单图层改脸。**

1. 用能分图层的软件打开 `tex\body.png`。
2. 复制一份。
3. 只改眼睛和嘴，身体一个像素都别动。
4. 导出成同名 PNG，尺寸一样，透明背景。

**用 AI 改：** 上传主图，让它"保持其余部分完全不变，只把眼睛改成弯弯的笑眼"。
结果通常会对不齐，要手动修。

**画布对齐的诀窍：** 先把主图垫在下面调低透明度，在上面画。
导出前把垫底那层隐藏。

### 验收

导一份进 Coopanion，点「对话」，让它做个开心的表情，看脸有没有变。
或者导入后直接看桌面，它会自己随机做表情。

## 阶段 4 · 清单与词表

### 要做的事

1. 工具里滚到「第三步」。
2. 写清楚你要的宠物。两三句话，说外形、颜色、动作特点、性格。
3. 点「AI 生成 figure.json」。

### 好描述和坏描述

**坏的：**

```
一只可爱的猫
```

AI 只能写出一堆空话，`about` 全是"可爱的猫"，后面 AI 陪聊时它会不知道自己长什么样。

**好的：**

```
一只圆脸的橘猫，右耳缺了一角，尾巴很短，走路一摇一摆。
高兴会原地蹦两下，生气会炸毛，困了直接趴下睡。
被拎起来会蹬腿乱蹬，摸头会眯眼。
```

### AI 只改这三个字段

| 字段 | 作用 | 为什么重要 |
|---|---|---|
| `name` | 界面上显示的名字 | — |
| `about` | 给 AI 看的形象描述 | Coopanion 里的 AI 读这段才知道自己是什么、有多大、怎么走路。写得越具体，它说话越像这个角色 |
| `vocab` | 表情和动作词表 | 决定它能做什么。没有词就只能走路发呆 |

`figure.js` 和模板结构都由工具保留，AI 动不了。

### 词表的硬规则

| 规则 | 违反后果 |
|---|---|
| `id` 只能小写字母数字横杠 | 整包被拒 |
| `kind` 只能是 `expression` 或 `motion` | 该项被跳过 |
| 中文别名不能含逗号、顿号、空格、`【】<>` | 整包被拒 |
| 所有 id 和别名全局唯一 | 整包被拒 |
| 每项必须有 `about` | 整包被拒 |
| `seconds` 必须大于 0 | 整包被拒 |

**最容易踩的坑：** 给英文别名写成跟 id 一样。
比如 `id: "happy"` 配 `names: {"en": ["happy"]}`。
Coopanion 会把 id 和别名放进同一个池子查重，这样必然重复，整包被拒。

模板就是因为这个踩过一次，已经改成只有中文别名。
如果你自己加英文别名，**必须和 id 不同**。

### 只用这些词 id

套件已经实现了这些，写了就有效果：

**表情（18 个）**
`neutral` `happy` `wink` `love` `shy` `surprised` `angry` `sad` `sleepy`
`thinking` `smug` `pout` `worried` `determined` `flustered` `scared` `excited` `cry` `confused`

**动作（18 个）**
`stand` `jump` `hop` `look` `turn` `nod` `shake` `spin` `sit` `sleep`
`dizzy` `walk` `run` `wave` `bow` `shiver` `flap` `dance`

不在这个表里的 id，即使写进 `vocab` 也不会有什么效果。
要么用表里的，要么自己在 `figure.js` 里实现（进阶）。

### 验收

- AI 返回后，界面显示「写好 N 个词」。
- N 在 12 到 22 之间比较合适。
- 下面的「错误」区块是空的。

## 阶段 5 · 校验

### 要做的事

点「检查这一包」。

这一步会做三层检查：

| 层 | 查什么 | 谁做的 |
|---|---|---|
| 1 | 字段格式、id 正则、词表重名、路径、大小 | 工具自己的校验器（照抄 Coopanion 源码规则） |
| 2 | `figure.js` 语法 | `node --check` |
| 3 | 能不能被加载：导出名对不对、工厂返回的 body 有没有 step/layout/do、draw 会不会崩 | `test_pack.mjs` 模拟 Coopanion 装载 |

### 三种结果

**通过。** 绿色，加载测试全 `ok`。进阶段 6。

**有红色错误。** 一条一条改。常见错误看 `06` 文档。

**只有黄色提示。** 能导入，但可能有隐患。比如：
- 「vocab 是空的」→ 宠物没表情
- 「缩略图不存在」→ 列表里没图
- 「音效文件不存在」→ 那一条音效被跳过

### 手动跑测试

不想开界面的时候，直接命令行：

```
cd /d E:\AI\Coopanion的宠物制作工具\studio
node tools\test_pack.mjs ..\projects\blue-cat\pack
```

返回码 0 就是通过。
输出里 `FAIL` 开头的必须改，`warn` 开头的看情况。

## 阶段 6 · 打包导入测试

### 要做的事

1. 「打包成 zip」。输出在 `dist\<id>-<版本>.zip`。
2. 打开 Coopanion → 左侧「装扮」。
3. 右上「导入形象包」。
4. 「选择 zip 文件」，选 `dist` 里那个。
5. 它会列出来，显示名字、作者、几个词。
6. 点确认导入。
7. 在「形象」那一排找到它，点一下换上。

### 导入后要看的六件事

| 看什么 | 正常 | 不正常说明 |
|---|---|---|
| 桌面上出现宠物 | 站在屏幕下方 | 全白/全黑 → 图片问题 |
| 它在走路 | 左右移动，有起伏 | 不动 → 可能 `can.walk` 是 false |
| 拖动它 | 会被拎起来，有挣扎表情 | 拖不动 → 点击判定圆不对 |
| 点「对话」说话 | 会做表情和动作 | 只会动不会变脸 → 表情图缺失 |
| 右键菜单 | 有「换下」「设置」等 | — |
| 挂机两分钟 | 会自己坐下或睡觉 | — |

### 出问题怎么回到工具

Coopanion 里不用卸载。回去改 `pack\`，重新打包，再导入一次。
它会问要不要替换，选替换。

改完一定要重新打包。**直接改 `pack\` 不会生效**，因为 Coopanion 读的是导入时复制过去的那一份。

## 阶段 7 · 迭代修复

### 把问题变成改法

| 现象 | 原因 | 改哪里 |
|---|---|---|
| 桌面上是白方块 | 图不透明 | 重做透明背景 |
| 宠物很小 | 图里留白太多 | 重新裁图，让主体占满 |
| 脚悬空 | 图底部有透明留白 | 裁掉底部空白 |
| 宠物陷进任务栏 | 图底部有多余内容 | 同上 |
| 边缘有白边 | 抠图不干净 | 重抠，或缩小时加 1px 内缩 |
| 表情没变化 | 缺 `tex\face-<表情>.png` | 补图，或接受统一表情 |
| 开心时变成别的生物 | 模板自带的三张表情没删 | 删 `tex\face-happy.png` 等 |
| 走路没有起伏 | `draw()` 里 `bob` 被改了 | 改回来，或调数值 |
| 导入报「id 不合法」 | 大写或下划线 | 改 `figure.json` 的 `id` |
| 导入报「名字重复」 | 别名和 id 撞了 | 改 `vocab` 的 `names` |
| 导入后立刻闪回原形象 | `figure.js` 运行报错 | 跑 `test_pack.mjs` 看具体哪步 |
| 说话时不动 | 模板没做口型 | 属于进阶，不做也正常 |

### 一轮完整的迭代

```
改 pack\ → 点检查 → 打包 → Coopanion 导入替换 → 看效果 → 再改
```

熟练后一轮三分钟。

## 进阶：想做得更像专业包

内置的大鲸鱼包是分层贴图，40 多个图层，配 8 套配色。
它的结构在 `02-形象包格式规范.md` 的 4.1 节。

要做成那样，工作量的分布大概是：

| 工作 | 占比 |
|---|---|
| 画分层素材 | 70% |
| 拆分和命名 | 15% |
| 调骨骼锚点 | 10% |
| 写清单 | 5% |

**不建议第一只宠物就做分层。** 先做单图层跑通，第二只再升级。

## 时间参考

按我实际做的经验估：

| 情况 | 从零到导入成功 |
|---|---|
| 用现成图 + 不做表情 | 30 分钟 |
| 用现成图 + 做 3 张表情 | 2 小时 |
| 让 AI 画主图 + 做 3 张表情 | 3 到 4 小时 |
| 分层包 | 两个工作日以上 |

第一次会慢，因为要摸清 Coopanion 的脾气。
第二只会快很多。
