# Coopanion 形象包格式规范

本文是从 Coopanion v0.2.13 安装目录源码里读出来的真实格式。
不是猜测。每一条都能在执行文件里找到出处。

源码位置（只读参考，不要改）：

```
D:\AIGJ\Coopanion\resources\app\node_modules\cortico-world-desktop-pet\
  src\packs.ts          ← 清单校验，权威
  src\pack-import.ts    ← 导入规则、大小上限
  web\figure-frame.js   ← 包代码的运行契约
  web\kit\body.js       ← 官方套件，帮你做走路/表情/拖拽
  web\coo\              ← 内置包示例（纯代码绘制）
  web\whale\            ← 内置包示例（分层贴图）
```

---

## 一、一个形象包就是一个目录

目录里必须有 `figure.json`。
导入时，Coopanion 最多往下找 3 层。

```
mypet/
  figure.json      ← 必须，清单
  figure.js        ← 必须（entry 指向它），宠物身体的代码
  thumb.png        ← 可选，列表里的缩略图，不能超过 1 MB
  tex/             ← 可选，你自己约定的素材目录
  sounds/          ← 可选，音效
```

导入方式有两种，界面都支持：

1. 把整个目录压成 zip，选「选择 zip 文件」。
2. 直接选目录，或把目录拖进窗口。

解压后总大小不能超过 **128 MB**。
超过会直接报错，不会导入一半。

## 二、figure.json 的字段

### 2.1 必填字段

| 字段 | 类型 | 规则 | 错了会怎样 |
|---|---|---|---|
| `manifest` | 整数 | 现在是 `2` | 报「版本不对」 |
| `api` | 整数 | 现在是 `2` | 报「版本不对」 |
| `id` | 字符串 | 正则 `^[a-z0-9][a-z0-9-]{0,31}$`，全小写 | 包被拒绝 |
| `version` | 字符串 | 建议 `1.0.0` | 缺失时按 `0.0.0` |
| `name` | 对象 | 至少一个语言键，如 `{"zh":"小蓝","en":"Blue"}` | 报「没有名字」 |
| `about` | 对象 | 同上。这是给 AI 看的"我长什么样" | 报「没有描述」 |
| `entry` | 字符串 | 包内相对路径，如 `figure.js` | 报「入口不对」 |
| `export` | 字符串 | 模块导出的工厂函数名 | 运行时报错 |
| `vocab` | 数组 | 表情/动作词表，至少一项 | 报「词表不是数组」 |

`id` 不能叫 `coo`。`coo` 是内置包专用，写了会被拒绝。

`about` 非常重要。它不是随便写的简介。
AI 会读这段文字，才知道自己的形象是什么、能做什么表情。
写得越具体，AI 用表情就越准。

### 2.2 可选字段

| 字段 | 类型 | 说明 |
|---|---|---|
| `author` | 字符串 | 作者名 |
| `license` | 字符串 | 许可 |
| `credits` | 数组 | `[{role, name, url?}]` |
| `model` | 字符串 | 额外的模型 JSON 路径，如 `model.json` |
| `thumb` | 字符串 | 缩略图路径，只认 png/jpg/jpeg/webp |
| `axes` | 数组 | 装扮轴，对应界面的「配色」「服装」 |
| `presets` | 数组 | 预设组合，每个 preset 要给出每条轴的选项 |
| `sounds` | 对象 | 自带音效，`{名字:{file,kind,volume}}` |
| `can` | 对象 | `{"walk": true}`。走路开关，默认开 |
| `moves` | 数组 | 自定义移动目标，最多 8 个 |
| `needs` | 数组 | 只支持 `"windows"`，要读窗口位置时才填 |
| `voice` | 对象 | `{"pitch": 1}`，范围 0.5 到 2 |
| `effects` | 对象 | `{"reach": 0}`，特效超出身体的距离，最大 2 |
| `bubble` | 对象 | 气泡配色，`{light:{fill,text,line}, dark:{...}}` |

### 2.3 装扮轴的规则

`axes` 是界面上的选项卡，也是「配色」和「服装」的来源。

```json
"axes": [
  {
    "id": "palette",
    "name": { "zh": "配色", "en": "Colours" },
    "options": [
      { "id": "mint", "name": { "zh": "薄荷绿" }, "thumb": "thumbs/mint.png" }
    ]
  }
]
```

- 轴 `id` 用 `id` 规则（全小写）。
- 选项 `id` 用 `^[a-z0-9]{1,24}$`，**不能有横杠**。
- 选项 id 会用 `-` 连起来变成 `scheme`。所以选项 id 里不能再带横杠，否则解析会乱。
- `presets` 里每个 preset 必须给全每条轴的选择，缺一条整包报错。

最少可以一条轴都不要：`"axes": []`。
这时界面上就没有配色和服装，只有形象本身。

## 三、figure.js 的运行契约

这是最关键、也最容易做错的部分。

形象包不是纯配置。Coopanion 会真的加载你的 JS，并调用它。
它在沙箱里运行：没有网络，只能和主页面用 `postMessage` 说话。

### 3.1 工厂函数

`entry` + `export` 拼起来决定调用谁。

```js
export function createMyPet(base, { model, scheme, kit, loadImage, asset, host }) {
  // 必须返回一个 body 对象
}
```

参数说明：

| 参数 | 含义 |
|---|---|
| `base` | 包的 URL 根，用来拼资源地址 |
| `model` | `figure.json` 里 `model` 指向的 JSON 解析结果 |
| `scheme` | 当前选中的装扮方案 id |
| `kit` | 官方套件，`kit.createBody` 帮你做全部动作 |
| `loadImage` | 异步载图，`loadImage(url)` 返回 Promise |
| `asset` | 拼路径，`asset('tex/body.png')` 得到完整 URL |
| `host` | `root`、`bounds()`、`emit()`、`sound()`、`start` |

### 3.2 body 对象

必须实现三个方法：

| 方法 | 作用 |
|---|---|
| `step(dt)` | 推进一帧并绘制。`dt` 是秒 |
| `layout()` | 报告当前状态：位置、朝向、模式、是否在动等 |
| `do(word)` | 执行一个词，表情或动作 |

可选方法：`walk`、`move`、`stopWalk`、`pointer`、`drop`、`shift`、
`place`、`set`、`cue`、`talk`、`setScheme`、`resize`、`dispose`。

**不要自己实现这些。** 用 `kit.createBody` 一次全拿到。

### 3.3 用套件的最短写法

这就是内置 Coo 的全部入口代码，只有 10 行：

```js
import { COO_CSS, cooFigure, normalizeSkin, skinCss } from './coo.js';

export function createCooBody(base, { kit, host }) {
  const start = { ...host.start, skin: normalizeSkin(host.start?.skin) };
  const body = kit.createBody(
    { ...host, start },
    { figure: cooFigure(), css: COO_CSS, skinCss: (s) => skinCss(s) }
  );
  return body;
}
```

你要做的只有一件事：**换掉 `figure`**。

### 3.4 figure 对象

套件会每帧调用 `draw`，其余全部由它负责。

```js
{
  draw(petG, face, frame) {},   // 把图形画进 petG
  setSkin(skin) {},             // 装扮变了，可选
  get anchors() { return {} },  // 眼泪、气泡的锚点，可选
  get extent() { return [20, 12, 236, 256] },  // 身体边界，可选
  get hits() { return [[128, 128, 108]] }      // 点击判定圆，可选
}
```

坐标系：256×256 的方格，脚在 `y = 256`，默认朝右。

`frame` 里能用到的：

| 字段 | 含义 |
|---|---|
| `frame.face` | 当前表情名，如 `happy` |
| `frame.mode` | 当前模式，如 `walk`、`sit`、`sleep` |
| `frame.modeT` | 这个模式持续了多久 |
| `frame.t` | 总时间，拿来算呼吸和摆动 |
| `frame.talk` | 说话音量，0 到 1 |
| `frame.drowse` | 困倦程度，0 到 1 |
| `frame.gesture` | 手势，`{kind, k}` 或 null |

**用贴图就靠这个 `draw`。** 在 `petG` 里塞一个 `<image>` 就行：

```js
draw(petG, face, frame) {
  const bob = Math.sin(frame.t * 2.2) * 3;      // 呼吸浮动
  petG.innerHTML =
    `<image href="${url}" x="28" y="${18 + bob}" width="200" height="238"
            preserveAspectRatio="xMidYMax meet"/>`;
}
```

`innerHTML` 每帧重写会重新载图，画面可能闪。
生产做法是建一次元素，之后只改 `transform`。
模板包 `studio/templates/minimal-pack/` 里给的是不闪的版本。

## 四、素材格式

| 类型 | 允许的扩展名 | 说明 |
|---|---|---|
| 图片 | `.png` `.jpg` `.jpeg` `.webp` | 不支持 gif、svg、avif |
| 音频 | `.ogg` `.mp3` `.wav` | 不支持 m4a、flac |
| 代码 | `.js` `.mjs` | 必须是标准 ES 模块 |
| 缩略图 | png/jpg/jpeg/webp，≤ 1 MB | 超了自动忽略，不报错 |

**视频不能直接进包。** Coopanion 没有视频播放能力。
视频的用途只有两个：

1. 抽帧，挑一帧当参考，再画成贴图。
2. 给 AI 看动作，让 AI 生成对应的表情和动作词。

### 4.1 参考内置包的贴图分法

内置大鲸鱼包 `web/whale/` 是分层贴图，共 40 多个图层。
它把身体拆成这些部位：


## 五、vocab 词表

`vocab` 决定 AI 能用什么表情和动作。
每一项的结构：

```json
{
  "id": "happy",
  "kind": "expression",
  "names": { "zh": ["开心", "高兴"], "en": ["happy"] },
  "about": { "zh": "眼睛弯成 ^ ^", "en": "eyes curve into ^ ^" },
  "seconds": 0.9
}
```

规则：

| 项 | 规则 | 违反后果 |
|---|---|---|
| `id` | `^[a-z0-9][a-z0-9-]{0,31}$`，全局唯一 | 整包拒绝 |
| `kind` | 只能是 `expression` 或 `motion` | 该项被跳过，不报错 |
| `names` | 每个语言是字符串数组 | 整包拒绝 |
| 名字内容 | 不能含 `,` `，` `、` 空格 `【】<>` | 整包拒绝 |
| 名字长度 | 不超过一个标记能装的长度 | 整包拒绝 |
| `about` | 必须有，且非空 | 整包拒绝 |
| `seconds` | 必须大于 0 | 整包拒绝 |
| `lasting` | 可选，`true` 表示持续不自动结束 | — |

所有名字（含 id）全局不能重复。两个词共用一个中文名会让整包失败。

内置包给了 37 个词，可以整段抄。抄了就要实现对应画法。
不实现也不会崩，只是那个表情看起来和默认一样。

## 六、导入时会被拒的情况

按导入代码逐条列。出现这些，界面上会说原因。

| 情况 | 提示大意 |
|---|---|
| 目录里没有 `figure.json` | 找不到清单 |
| JSON 语法错 | 清单不是合法 JSON |
| `manifest` 或 `api` 比 2 大 | 版本太新 |
| `manifest` 或 `api` 比 2 小 | 版本太旧 |
| `id` 大写、带下划线、超过 32 字符 | id 不合法 |
| `id` 写成 `coo` 或 `whale` | 内置 id 不可占用（官方文档写的两个保留名） |
| `name` 或 `about` 空 | 缺名字或描述 |
| `entry` 是绝对路径、或含 `..` | 入口路径不合法 |
| 两条轴里选项 id 重复、或带横杠 | 轴或选项不合法 |
| preset 少给了某条轴 | 预设缺轴 |
| vocab 有重复名字 | 名字重复 |
| 解压后超 128 MB | 包太大 |
| 文件数超过 2048 个 | 条目太多（逐帧动画最容易超） |
| 单个文件超过 16 MB | 单文件太大 |
| `figure.json` 超过 256 KB | 清单太大 |
| 两个包用同一个 id | id 重复（同 id 导入会问你要不要更新） |
| 替换已安装的包但没确认 | 冲突，需选择替换 |

会被「跳过但不报错」的：

- `kind` 不认识的词
- 音效文件不存在
- 音效扩展名不是 ogg/mp3/wav
- 音效 `kind` 不认识
- `can.walk` 不是布尔
- `needs` 里有不认识的值

这些都只影响那一项，包照样能用。

## 七、安装后放在哪里

用户导入的包会被复制到数据目录下的 `packs/<id>/`。
你这台机器的数据目录是：

```
D:\AIGJ\Coopanion\data\
```

内置包永远在 `resources\app\node_modules\cortico-world-desktop-pet\web\` 下。
内置包不会被卸载，也不会被同 id 的包覆盖。

想手动删掉某个包：在界面里删，或者删 `packs\<id>` 目录。
不要在程序运行时手改内置包。

## 八、最小可用包（必须背下来的部分）

一个能跑起来的最小包，只有三个文件：

```
minimal-pack/
  figure.json
  figure.js
  tex/body.png
```

`figure.json` 最少要有这些：

```json
{
  "manifest": 2,
  "api": 2,
  "id": "mypet",
  "version": "1.0.0",
  "name": { "zh": "我的宠物", "en": "My Pet" },
  "about": { "zh": "一只圆滚滚的小家伙，会走会坐会睡。", "en": "A round little creature." },
  "entry": "figure.js",
  "export": "createMyPet",
  "axes": [],
  "presets": [],
  "vocab": [],
  "sounds": {},
  "can": { "walk": true }
}
```

`vocab` 给空数组也能通过校验。
但 AI 就没有词可以用，宠物只会走路和发呆。
所以实际制作时至少要给 10 个词。

完整可跑的模板在 `studio/templates/minimal-pack/`。
那个已经配好 20 个词、5 个表情贴图位、呼吸浮动和不闪的绘制方式。

## 九、贴图命名（模板 figure.js 认这套名字）

模板里的 `figure.js` 只做一件事：按当前状态挑一张图，画到 256×256 的格子里。
它认下面这几个文件名。有就用，没有就退回上一级。

| 文件 | 什么时候用 | 没有会怎样 |
|---|---|---|
| `tex/body.png` | 站着、发呆、被拎起 | 必须要有，没有就是空白 |
| `tex/face-<id>.png` | 该表情生效时 | 退回 body，表情不显示 |
| `tex/walk-00.png` … | 走、跑、跳舞 | 退回 body，走路变成平移 |
| `tex/sit.png` | 坐下 | 退回 body，坐姿还是站着 |
| `tex/sleep.png` | 睡觉 | 退回 body，睡着也站着 |

`<id>` 只能是 vocab 认的这些：
`neutral happy wink love shy surprised angry sad sleepy thinking smug pout worried determined flustered scared excited cry confused`

走路帧从 `walk-00` 开始，中间不能断。断了后面的都用不上。
10 张以内都行，越少循环越短。

## 十、两张图之间不能跳

所有贴图里，角色的脚必须落在**同一高度**，通常是画布最底边。

如果不齐，走路时角色会一上一下。
工具在同步素材时会自动把不透明部分挪到底边，但前提是装了 Pillow。

自己检查的办法：在 PS 里打开两张图，看脚底是不是贴着画布底边。

## 十一、为什么表情图不生效（踩过的坑）

`figure.draw(petG, face, frame)` 的第二个参数 `face` **是一个对象**，
里面是眼睛、嘴、腮红这些绘制参数，不是表情名。

表情名在第三个参数里，是 `frame.face`，一个字符串。

写成 `faceUrls[face]` 永远取不到东西，因为键是 `[object Object]`。
结果就是表情图一张都用不上，宠物一直用主图 —— 看起来像个贴纸。

正确的写法：

```js
const url = urls.faces[frame.face] || urls.main;
```

## 十二、给整身图做表情（facegen.py）

整身图路线的角色，表情没法「换一张整身图」——
因为走路、坐着、被拎起时姿势都不一样，换图会闪一下。

正确做法是**只换脸那一小块**：

1. 从主图裁一块「脸区」小图（含眼睛、嘴、腮红范围）。
2. 表情只改这一块里的眼睛和嘴，其余像素跟主图完全一致。
3. 渲染时把这块小图叠在整身图上，位置对齐。

`studio/facegen.py` 就是干这个的：

```bash
python studio/facegen.py 包目录/tex/body.png 包目录/tex
```

会输出 `face-happy.png`、`face-cry.png`…… 一整套，尺寸和主图一样大。

### 脸区坐标

自动识别虹膜来找眼睛。如果认歪了（头发和眼睛粘在一起就会认歪），
在 `tex/` 下放一个 `face-layout.json` 手动标：

```json
{ "eyes": [[184,130,218,166],[241,130,274,166]], "mouth": [214,170,238,190] }
```

四个数依次是 `左, 上, 右, 下` 的像素坐标，从主图上量。

### 叠加时必须跟着头部走

同一个人物的 idle 各帧，头会有几像素漂移（呼吸、轻微晃动）。
小图固定在一个坐标上叠，眼睛就会错开、出现重影。

所以要把每帧的漂移量记下来：

```js
const SHIFT = { "idle0": [0, 0], "idle01": [0, -0.51], "idle04": [-0.16, 1.91] };
```

单位是 256 逻辑格，不是像素。换算：`像素 × (178.9 / 458)`。

漂移量怎么量：取虹膜（浅黄那圈）的质心，跟主图比，差多少就是多少。

### 只盖在能对上的帧上

走、跑、睡、被拎起、做动作时，姿势对不上，**不要盖表情小图**，
这些帧本身已经有表情了（原素材画好了）。判断条件：

```js
if (key in SHIFT) { /* 只有站立的 idle 帧才盖 */ }
```

### 眨眼

`frame.blink` 是 kit 给的 0~1 数值，超过 0.3 就换成闭眼的图，
这样宠物会自己眨眼，立刻就不像静态贴纸了。

闭眼这张图不要用 `happy`（`^^` 是笑眼），要单独做一张平眼皮的，
`facegen.py` 里对应 `sleepy`。
