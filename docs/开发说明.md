# 开发说明

给想改代码的人看的。讲清楚三个文件各自管什么、接口长什么样、加功能从哪下手。

---

## 整体结构

```
浏览器 (web/index.html)  ──JSON──▶  server.py  ──▶  projects/<id>/
       (web/preview.html)   ◀─JSON──  (http.server)      pack/  ← 打包内容
                                                          raw/   ← 原始素材
```

没有框架，没有数据库，没有构建步骤。

- 服务端：Python 标准库 `http.server` + Pillow
- 前端：一个 HTML 文件，内联 CSS 和 JS，没有打包工具
- 存储：就是磁盘上的文件夹

所以改完刷新页面就生效，服务端改动重启一下就行。

## 三个 Python 文件

### `server.py`（约 2100 行）

一个文件里塞了六件事，按出现顺序：

| 段落 | 干什么 |
|---|---|
| 常量与规则 | 路径、id 正则、表情 id 表、音效名表、体积上限 |
| 基础工具 | `read_json` / `write_json` / `save_data_url` / `safe_filename` |
| 清单校验 | `validate_pack()` —— 全部导入规则都在这 |
| 清单修复 | `fix_manifest()` / `fix_pack()` —— 幂等，可重复跑 |
| 素材处理 | `sync_raw_textures()` / `normalize_bottom()` / `frame_to_walk()` |
| 请求处理 | `Handler` 类，每个接口一个 `_xxx` 方法 |

**`validate_pack(folder)` 返回 `(errors, warnings, info)`。**
所有规则集中在这一个函数里。要加规则就在这里加，前端不用动。

**`fix_manifest(raw)` 是纯函数。** 输入清单字典，输出改好的字典和改动说明。
修一条记一条，方便回显给用户。

### `autogen.py`（约 320 行）

纯 Pillow，不联网，不依赖 ffmpeg。

| 函数 | 作用 |
|---|---|
| `make_walk(body_path, out_dir, frames=6)` | 切上下半身，绕髋关节反相转腿，上身反向位移，落地压扁 |
| `make_pose(body_path, kind, out)` | `sit` 压到 42%，`sleep` 压到 30% 再转 90° |
| `make_sounds(out_dir)` | 合成 20 条 wav，名字和运行时对齐 |
| `_hit` / `_tone` / `_noise` / `_mix` | 音效合成原语 |

走路的自然度全靠 `make_walk`。要改成「视频描出的帧」，就在这一层替换。

### `facegen.py`（约 480 行）

从整身图生成表情小图。回旋余地最大的一块。

关键点三个：

1. **脸区坐标从 `tex/face-layout.json` 读。** 没有就自动找虹膜。
   自动识别会被头发干扰，所以手动坐标永远优先。
2. **抹眼睛时要绕开头发。** 用灰发的**连通块**做掩码，不能按颜色判断。
   按颜色判断会把眼白和抗锯齿边当头发留下，闭眼后留一圈残影。
3. **先在原尺寸上抹，再放大画。** 反过来做边缘会糊。

输出的每张 `face-*.png` 和主图一样大。渲染时按帧位移叠上去。

## HTTP 接口

全部是 JSON 进 JSON 出。只接受本机请求。

### GET

| 路径 | 参数 | 返回 |
|---|---|---|
| `/` | — | 制作台页面 |
| `/preview` | `id` | 预览页 |
| `/api/projects` | — | 项目列表（含素材数、词数、错误数）。带 mtime 指纹缓存 |
| `/api/assets` | `id` | 该项目 `raw/` 的文件名列表 |
| `/api/config` | — | 已存的地址、模型名。**不返回 Key** |
| `/api/env` | — | Pillow / ffmpeg / node 是否可用 |
| `/api/ffmpeg` | — | ffmpeg 能不能用 |
| `/api/preview-data` | `id` | 预览页要的全部数据 |
| `/api/packfile` | `id`, `p` | 包内单个文件（限 `tex/` 和 `sounds/`） |
| `/api/thumb` | `id`, `n` | `raw/` 里单张图的缩略图 |

### POST

| 路径 | 参数 | 说明 |
|---|---|---|
| `/api/project/create` | `id`, `name` | 建项目，复制模板 |
| `/api/project/upload` | `id`, `files[]` | 每项 `{name, data, slot}`，`data` 是 data URL |
| `/api/project/main` | `id`, `name` | 把某张图设为主图 |
| `/api/project/video` | `id`, `name`, `data`, `count`, `bg`, `tol` | 抽帧并处理成走路帧 |
| `/api/config` | `base`, `key`, `model` | 存配置。Key 存到用户目录 |
| `/api/ping` | — | 用已存配置发一次请求，回一句话和耗时 |
| `/api/ai/generate` | `id`, `brief` | 让模型写清单 |
| `/api/validate` | `id` | 校验，返回 `{ok, errors, warnings, info}` |
| `/api/fix` | `id` | 一键修复，原件备份 |
| `/api/clean-faces` | `id` | 模板占位表情移到 `tex/_unused/` |
| `/api/autogen` | `id`, `targets[]` | `walk` / `sit` / `sleep` / `sounds` |
| `/api/package` | `id`, `force` | 打包成 zip |
| `/api/open` | `kind` 或 `id` | 打开文件夹。**只允许项目目录内** |
| `/api/delete` | `id`, `confirm` | 删项目，`confirm` 必须等于 `id` |

### 安全边界

`_local_only()` 在每次 POST 前检查三件事：

1. `Host` 必须是 `127.0.0.1` / `localhost` / `::1`
2. `Origin`（有的话）必须是本机
3. `Content-Type` 必须是 `application/json`

外加请求体上限 96 MB。`/api/open` 会对目标路径做前缀校验。

**改这几处要小心。** 这是挡跨站请求的唯一一道墙。

## 前端的约定

### 一个请求函数管所有

```js
api('/api/projects')                    // GET
api('/api/validate', { id: cur })       // POST
```

失败会抛异常，消息就是服务端返回的 `error` 字段。

### 提示信息四色

```js
msg('aiMsg', 'ok', '成功')      // 绿
msg('aiMsg', 'err', '失败')     // 红
msgList('aiMsg', 'warn', '标题', [])  // 黄，列表
msg('aiMsg', 'info', '进行中')  // 灰
```

### 状态只有 `cur`

当前项目 id 存在全局 `cur` 里。切项目就是改它再刷一遍。

页面支持 `?id=xxx` 直达某个项目。方便把截图发给别人看。

## 加东西从哪下手

### 加一个校验规则

改 `validate_pack()`。错误用 `errors.append()`，提示用 `warnings.append()`。
带上具体文件名和怎么改，别只写「不合法」。

### 加一个分区

1. `web/index.html` 里加卡片，`data-slot` 写新值
2. `_upload()` 里加分支，决定落盘文件名
3. `sync_raw_textures()` 里加同步规则
4. `figure.js` 模板里决定怎么用它

### 换掉合成走路

只改 `autogen.py` 的 `make_walk()`。签名不变，别的地方都不用动。

### 接图像生成模型

现在是空的。要在 `_ai_generate()` 旁边加一条新链路：

1. 拿 `brief` 和主图去调生图接口
2. 把结果落到 `raw/face_<id>.png`
3. 调 `sync_raw_textures()`

注意上游多半只给 1024 方图，得自己缩到 512 并贴底边。

## 测试

```bash
# 语法
python -m py_compile studio/server.py studio/autogen.py studio/facegen.py
node --check studio/templates/minimal-pack/figure.js   # 若报 export 错，复制成 .mjs 再查

# 清单校验
python -c "import sys;sys.path.insert(0,'studio');import server;print(server.validate_pack('studio/templates/minimal-pack'))"

# 模拟装载（需要 Node）
node studio/tools/test_pack.mjs projects/yy/pack
```

`test_pack.mjs` 会真的读磁盘检查每个贴图，还会抽样验证：

- 换表情会不会换图
- 走路会不会切帧
- 坐、睡有没有专属图
- 第二帧有没有重建元素（重建就会闪）

## 代码风格

- 中文注释，讲「为什么」不讲「是什么」
- 报错信息写给人看，带上怎么改
- 不引第三方依赖，除非躲不开（Pillow 是唯一的例外）
- 前端不引框架，一个 HTML 文件带到底
