# 07 · 素材清单：要做什么图、什么视频、什么音效

这份文件回答一个问题：**想让宠物真的动起来，我到底要准备什么。**

工具能自动补一部分，但补出来的只能看。真图永远更好。下面按"最低能跑"和"真好看"两档写。

---

## 一、两档配置

### 最低档：1 张图（能跑，动起来很假）

| 文件 | 数量 | 说明 |
|---|---|---|
| `body.png` | 1 | 透明底全身图，正面朝右，脚贴画布底边 |

其余交给「一键补齐」：6 帧走路、坐姿、睡姿、20 个音效。
走路是程序变形，纸片人感明显。

### 完整档：13 个文件（真好看）

| 用途 | 文件名 | 数量 | 优先级 |
|---|---|---|---|
| 主图 | `body.png` | 1 | 必须有 |
| 走路 | `walk_f00` … `walk_f05` | 6 | 最高，决定"活没活" |
| 表情 | `face_happy` `face_angry` `face_sad` `face_shy` `face_sleepy` `face_surprised` | 6 | 高 |
| 坐姿 | `mode_sit.png` | 1 | 中 |
| 睡姿 | `mode_sleep.png` | 1 | 中 |
| 音效 | `sound_step.wav` 等 | 0 到 20 | 低，工具已能合成 |

放在 `projects\<你的id>\raw\` 里，或者在工具的「第二步」分区上传。
文件名里的大小写、下划线、横杠都不影响，工具认得。

---

## 二、共用要求（所有图都适用）

1. **透明底 PNG**。抠图不干净的边缘，走动时会出现白边。
2. **同一个角色，同一套画风**。换衣服、换发色、换线条粗细，一眼看得出来。
3. **脚必须在画布最底边**。差 40 像素，走路就一上一下飘。
   工具会自动把不透明部分挪到底边，但原始图对齐了更省事。
4. **画布统一**. 所有帧用同一个尺寸，建议 512×768 或 577×1024。
5. **朝向统一朝右**。Coopanion 会自己左右镜像，你不用画两套。

---

## 三、走路：最好的办法是拍/生成一段视频，再抽帧

单张图让 AI 画 6 个连贯动作，几乎做不到。
**一段 2 到 4 秒的循环走路视频，抽 6 帧，是目前最稳的路子。**

### 3.1 视频要求

| 项 | 要求 | 为什么 |
|---|---|---|
| 时长 | 2 到 4 秒 | 太短抽不出 6 帧，太长文件大 |
| 镜头 | 固定不动 | 镜头一动，帧之间角色位置就跳 |
| 朝向 | 正面偏右 30° 或纯侧面 | 纯侧面最像走路，正面偏右最像桌面宠物 |
| 动作 | 原地走，不前进 | 前进会跑出画面 |
| 背景 | 纯绿 / 纯白 / 纯色 | 好抠图 |
| 画布 | 竖构图，人占满高度 | 抽出来的帧直接能用 |
| 光线 | 均匀 | 明暗跳变会让循环闪 |

### 3.2 图生视频的提示词（可灵 / 即梦 / Vidu / Runway / Sora 都一样）

把你的 `body.png` 传进去当首帧，提示词写：

```
角色保持完全不变：同样的发型、同样的服装、同样的配色、同样的脸。
镜头固定不动，角色在原地做行走动作，双腿交替迈步，手臂自然摆动，
身体随步伐轻微上下起伏，裙摆（或衣摆）跟着轻轻晃动。
两秒完成两个完整步幅，最后回到和开始时相同的姿势。
纯白色背景，全身入画，脚始终在画面底部，不要镜头运动，不要转场。
```

要点：
- **写"角色保持完全不变"**。不写，AI 会顺手把你的角色重画一遍。
- **写"最后回到开始姿势"**。这样首尾帧能接上，循环时不跳。
- **写"镜头固定"**。默认它爱推镜头。

### 3.3 抽帧

工具里已经有「上传视频抽帧」，默认抽 6 帧。

如果你想自己抽，用 ffmpeg，抽 8 帧均匀分布：

```
ffmpeg -i walk.mp4 -vf "fps=4,crop=iw:ih:0:0" walk_f%02d.png
```

抽完检查两两之间有没有明显差异。都一样就是视频没动，重做。

命名 `walk_f00.png` 到 `walk_f07.png`，**必须从 00 开始连续**。
断一帧，后面的都用不上。

## 四、表情图怎么出

表情只改脸，身体必须一动不动。

### 4.1 做法（图生图 / 局部重绘）

1. 用 `body.png` 当底图。
2. 只框住脸，框外全部锁住（局部重绘 / inpaint）。
3. 每个表情单独生成，别一次生成九宫格。
4. 生成完对比一下身体轮廓，差太多就重来。

### 4.2 每个表情的提示词模板

把 `{表情}` 换掉，其余不动：

```
同一张图的局部重绘，只重画脸，身体、头发、服装、姿势、配色完全不变。
表情：{表情}。
保持原图的线条粗细和上色风格，保持透明背景，不要加文字。
```

对应填法：

| 文件名 | `{表情}` 填什么 |
|---|---|
| `face_happy` | 张嘴大笑，眼睛弯成月牙，脸颊泛红 |
| `face_angry` | 皱眉，嘴角向下，眼神有火气 |
| `face_sad` | 眼角下垂，嘴唇抿住，眼里有泪光 |
| `face_shy` | 脸红，视线偏开，嘴角微微上扬 |
| `face_sleepy` | 半闭眼，张嘴打哈欠 |
| `face_surprised` | 眼睛睁大，嘴张成 O 形，眉毛抬高 |
| `face_love` | 眼睛变成心形，脸颊通红 |
| `face_pout` | 鼓腮帮，嘴角下撇，眼神不服气 |
| `face_wink` | 一只眼闭上，另一只眼笑，嘴角上挑 |

能做到 6 个就先做 6 个，剩下的不补也能跑，只是做那个表情时会用主图。

## 五、坐姿和睡姿

| 文件 | 画面要求 |
|---|---|
| `mode_sit.png` | 坐在看不见的椅子上，膝盖朝前，手放腿上，头顶对齐主图高度的一半左右 |
| `mode_sleep.png` | 躺平，头朝左，身体横向占据画面，脸朝上或朝观众 |

这两张用图生图最省事，提示词：

```
同一角色，同一画风。改成{坐在地上的姿势 / 躺下睡觉的姿势}。
服装、发型、配色完全不变。纯透明背景，全身入画。
```

睡姿允许画布比其他图宽，工具会等比缩放到 256 的框里，不会变形。

## 六、音效：可以自己录，也可以让工具合成

工具能合成 20 个，够用。名字是固定的，Coopanion 按这些名字触发：

| 名字 | 什么时候响 | 建议音色 |
|---|---|---|
| `step` | 每走一步 | 轻轻的"嗒" |
| `jump` | 起跳 | 上扬的短音 |
| `land` | 落地 | 沉闷的"咚" |
| `grab` | 被拎起来 | 短促的"啾" |
| `poke` | 被戳 | 高频"叮" |
| `purr` | 被顺毛 | 低频呼噜 |
| `squeak` | 被捏 | 橡皮鸭 |
| `snore` | 睡着 | 呼吸声，可长 |
| `chirps` | 打招呼 | 三连短鸣 |
| `dance` | 跳舞 | 小鼓点 |
| `nod` `shake` `spin` `skid` `shiver` `look` `tick` `whoosh` | 各种动作 | 短音即可 |
| `surprised` `yawn` | 表情 | 上扬音 / 下滑音 |

要换成自己的：录一段 0.5 秒内的干净音，存成 `sound_step.wav` 放进 raw，工具会自动接上。
音量建议 -12 dB 左右，太响会吵人。

---

## 七、一致性怎么保住

AI 最容易在这三处翻车：

1. **换脸**。每张图都写"保持完全不变"，并锁住局部。
2. **换线条**。同一个模型、同一个尺寸、同一个提示词模板，只改要变的部分。
3. **换位置**。脚不在同一高度，走起来就飘。工具会自动对齐底边，但别依赖它。

一条经验：**先生成 6 帧走路，觉得能看了，再去做表情。**
走路不行，表情做得再细也救不回来。

---

## 八、做完怎么验

1. 打开工具，选中项目。
2. 第二步看六个分区的数字：主图 1、走路 6、表情 6、坐姿 1、睡姿 1、音效 20。
3. 第四步点「检查这一包」，红字必须为零。
4. 点「打包成 zip」，去 Coopanion 导入。
5. 桌面上看四件事：站着会不会呼吸、走动时腿换不换、坐下会不会用坐姿、戳它有没有声。

哪一条不对，回来改对应的那一张图，重打一次。
