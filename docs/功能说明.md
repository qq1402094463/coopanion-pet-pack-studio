# 功能说明

这个文件讲清楚界面上每个东西干什么、什么时候点、点了会发生什么。

---

## 页面结构

```
┌──────────────────────────────────────────────────────────┐
│ 顶栏：接口状态 · 预览效果 · 打开工具文件夹               │
├──────────┬───────────────────────────────────────────────┤
│ 左栏     │ 第一步 接上大模型                             │
│ 项目列表 │ 第二步 分区放素材                             │
│ 新建项目 │ 第三步 让 AI 写清单                           │
│          │ 第四步 检查并打包                             │
└──────────┴───────────────────────────────────────────────┘
```

左栏点一个项目，右边四步才会出现。没选项目时只显示第一步。

---

## 顶栏

### 接口状态

显示「接口已配置」或「接口未配置」。

它只表示**本地存了地址和 Key**，不代表已经连通。
想确实知道通不通，去第一步点「保存并测速」。

### 预览效果

打开预览页，看这只宠物站起来、走、坐、睡、换表情。

必须先选中一个项目。没选会弹「先选一个项目」。

预览页的说明在本文最后。

### 打开工具文件夹

在文件管理器里打开项目根目录。

---

## 左栏

### 项目 id

你的形象包 id。**导入 Coopanion 后不能改。**

规则：

- 只能小写字母、数字、横杠
- 1 到 32 位
- 第一个字符不能是横杠
- 不能叫 `coo`，也不能叫 `whale`（这两个是内置保留名）

所以用 `my-cat`、`orange-fox` 这种。别用中文，别用空格。

### 显示名字

给人看的中文名。比如「小蓝」。这个可以随时改。

### 新建项目

按 id 建一套目录，并复制一份空白模板进去。

建出来的结构：

```
projects/<id>/
  project.json       项目元信息
  raw/               你上传的原始素材
  pack/              准备打包的内容
    figure.json
    figure.js
    thumb.png
    tex/
  frames/            视频抽出来的帧
  backup/            一键修复前的备份
```

新项目会自动把模板里那几个占位表情挪到 `tex/_unused/`。
不然你的宠物会顶着模板的蓝团子表情。

### 项目列表

每张卡片显示：id、素材数、词数、状态。

状态有三种：

- **通过** —— 能导入
- **N 提示** —— 能导入，但有问题建议改
- **N 错** —— 导不进去，必须改

## 第一步 · 接上大模型

只在你要让 AI 写清单时才需要。手写清单可以整段跳过。

### 三个输入框

| 框 | 填什么 | 例子 |
|---|---|---|
| 地址 | OpenAI 兼容接口的 `/v1` | `https://api.deepseek.com/v1` |
| Key | 服务商给的密钥 | `sk-...` |
| 模型 | 模型名 | `deepseek-chat` |

地址要写到 `/v1`，**不要再往后写** `/chat/completions`。

Key 留空时不会覆盖已存的。想换 Key 就重新填一遍。

### 保存并测速

保存配置，然后真的发一次请求。

成功会显示模型回了一句话，还有耗时。失败会显示具体报错。

### 配置存哪

不在项目目录里。见 [安装说明](../INSTALL.md) 第六节。

---

## 第二步 · 分区放素材

六个卡片。点卡片或把文件拖上去都行。右上角数字是已放的数量，变绿表示够了。

### 分区与命名

| 卡片 | 该放什么 | 落盘后叫 |
|---|---|---|
| 主图 | 一张透明背景的全身图，必有 | `raw/body.png` → `tex/body.png` |
| 走路帧 | 3 到 8 张，按顺序 | `raw/walk_f00.png` → `tex/walk-00.png` |
| 表情图 | `face_<表情id>.png` | `raw/face_happy.png` → `tex/face-happy.png` |
| 坐姿 | 1 张蹲坐的图 | `raw/mode_sit.png` → `tex/sit.png` |
| 睡姿 | 1 张躺睡的图 | `raw/mode_sleep.png` → `tex/sleep.png` |
| 音效 | 按音效名命名 | `sounds/<名字>.wav` |

上传后立刻同步进 `pack/`。不用再点别的。

### 表情 id 只能用这些

```
happy wink love shy surprised angry sad sleepy thinking smug
pout worried determined flustered scared excited cry confused
```

文件名认不出 id 的会被直接丢掉，不会报错。

中英对照：`face_开心.png` 也认。工具里有一张别名表。

### 音效名只能用这些

```
step jump land grab poke purr squeak snore chirps dance nod shake
spin skid shiver look tick whoosh surprised yawn
```

这 20 个名字是运行时写死的。名字不对等于没放。

**不放音效不算错。** Coopanion 自带一套合成音，没文件时会自动用它。
塞了 wav 反而会顶掉官方调好的音色，所以先别放，听一下再决定。

### 一键补齐：走路 + 坐睡 + 20 音效

用主图 `body.png` 生成：

- 6 帧走路（腿绕髋关节反相旋转，上身反向位移，落地压扁）
- 坐姿（下半身压到 42% 再整体压扁）
- 睡姿（压到 30% 后转 90°）
- 20 条音效（纯代码合成，不联网）

它**只补缺的**，已有的不覆盖。

生成的走路是纸片人走路。想要自然，去拍视频抽帧。

### 上传视频抽帧

选一段正面走路的视频，选抽几帧，它做四件事：

1. 均匀抽帧
2. 去背景（从四边灌色）
3. 按人物裁边
4. 底边对齐，贴进 512 方图

参数：

- **抠图开关** —— 背景和衣服颜色接近时（比如白裙白墙）关掉，只裁边
- **容差** —— 越大去得越狠，越小越保守。默认 12

抽出来的帧直接进走路分区。

### 素材缩略图

显示 `raw/` 里所有图。每张下面有「设为主图」。

点「设为主图」把这张图复制成 `body.png`。换造型、换角度时用。

## 第三步 · 让 AI 写清单

### 描述框

用一两句话写清楚你的角色长什么样、什么性格、怎么动。

```
一只圆滚滚的橘猫，耳朵缺一角，走路一摇一摆，生气会炸毛，喜欢趴着睡。
```

**别写「小女孩」「幼童」「巴掌大的」这类词。**
模型会误判成不合适的内容，直接返空。

改成「Q 版卡通角色」「Q 版人物」就行。

### AI 生成 figure.json

发一次请求，让模型输出清单。

它只改**名字、描述、词表**。`figure.js` 保持模板不动。

模型漏的词会自动补上（工具内置 38 个中文名）。
所以输出不完整也能拿到一个能通过的清单。

几种失败会给出人话解释：

| 显示 | 原因 |
|---|---|
| 模型没返回内容 | 上游安全过滤，或者 Key 没额度 |
| 模型没给出能解析的 JSON | 模型跑题了，换个模型或精简描述 |
| JSON 被截断 | 输出太长，工具会尽量补齐括号 |

### 只校验，不生成

不叫模型，直接跑校验。手写了清单想快速看结果时用。

## 第四步 · 检查并打包

### 检查这一包

跑三层校验：

1. **清单字段** —— 必填项、类型、id 格式、保留名
2. **词表** —— id 重复、名字重复、`kind` 取值、缺 `about` 或 `seconds`
3. **文件** —— 每张贴图、每个音效是否真的存在；占位图是否还在

结果分错误和提示。**错误必须清零才能打包。**

### 一键修复清单

自动修这几种：

- `about` 写成字符串 → 包成 `{zh: ...}`
- 词缺 `kind` → 按 id 补 `expression` / `motion`
- 用了 `aliases` → 改成 `names`
- 缺 `about` / `seconds` → 补齐
- 英文别名和 id 撞车 → 删掉别名
- `entry` / `export` 写错位置 → 归位
- 既不是表情也不是动作的词 → 移出词表，并告诉你移了哪些

改之前把原件备份到 `projects/<id>/backup/`。可以反复点，修过的不会再改。

### 打包成 zip

先校验。有错误就拦下来，除非你明确要强制打。

产物在 `dist/<id>-<版本号>.zip`。

`raw/`、`_unused/`、`backup/` 不会进包。

### 打开输出文件夹

打开 `dist/`。

### 挪走模板占位表情

把模板自带的蓝团子表情移到 `tex/_unused/`。

新项目建的时候已经自动做过一次。这个按钮是给老项目补的。

## 预览页

地址是 `/preview?id=<项目id>`。从顶栏「预览效果」进来。

### 中间画布

显示宠物当前的姿势。底部对齐，和真实渲染一致。

### 姿势按钮

站立、走路、坐着、睡觉、眨一下。

没有对应图的姿势会退回站立图，并在右侧「素材」里标红。

### 快捷键

- `空格` 切换走路
- `1` 到 `9` 切表情

### 右侧四块

- **这只宠物** —— 清单里的 `about`
- **表情** —— 点了就换脸。没有图的词显示原脸
- **显示** —— 大小滑块，透明格 / 白底 / 黑底
- **素材** —— 主图、走路帧数、坐姿、睡姿、表情数、音效数。缺的标红

透明格和白底都要看一眼。桌面上是浅色壁纸还是深色壁纸，效果不一样。

## 生成能力说明

工具里有两套生成脚本。都不是 AI 画图，都是程序合成。

### autogen.py

一张 `body.png` 变出走路、坐、睡、20 条音效。

走路按 cos 曲线做重心左右移，避免左右对称只剩 3 帧可区分。
帧间差异实测 21 到 38 像素。

### facegen.py

一张 `body.png` 变出一整套表情小图。

做法是**只换脸那一小块**。裁出脸区，抹掉原眼睛，重画眼睛和嘴。
其余像素跟主图完全一致。

所以表情能叠在每一帧呼吸动画上，身体不抖。

叠加时必须跟着头走。同一个人物的 idle 各帧，头会漂 1 到 5 像素。
小图固定在同一个坐标上叠，眼睛就会错位、出重影。

脸区坐标从 `tex/face-layout.json` 读。没有就自动找虹膜。

写法和坑见 [02-形象包格式规范](02-形象包格式规范.md) 第十二节。
