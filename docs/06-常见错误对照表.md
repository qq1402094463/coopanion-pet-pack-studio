# 常见错误对照表

报错原文是从 Coopanion v0.2.13 的中文语言包里抄出来的。
你在界面上看到的字应该和左边一栏一致。

用法：左边找到你看到的原文，中间是原因，右边是改法。

---

## 一、导入阶段被拒

这一栏的报错出现在「装扮 → 导入形象包」的选择界面。

| 你看到的原文 | 原因 | 怎么改 |
|---|---|---|
| `没有 figure.json` | 目录里没这个文件，或者 zip 套了太多层目录 | 把 `figure.json` 放到 zip 最外层。Coopanion 只往下找 3 层 |
| `figure.json 不是合法的 JSON：...` | 多了一个逗号、少了引号、用了中文引号 | 用工具点「检查」会指出问题。或把内容贴给 AI 让它找语法错 |
| `manifest 应为整数，是 "2"` | 写成了字符串 | 数字不要加引号 |
| `api 是 3，这一版只认到 2：要先更新应用` | 版本号写大了 | 改成 `2` |
| `manifest 1 是 2 之前的测试格式，读不了` | 版本号写小了 | 改成 `2` |
| `id 不合法："MyCat"` | 有大写字母 | 全改小写：`my-cat` |
| `id 不合法："my_cat"` | 有下划线 | 用横杠：`my-cat` |
| `id 不合法："..."` | 超过 32 位，或首字符是横杠，或含中文 | 缩短，字母开头 |
| `id coo 是内置形象的，换个 id 才能导入` | 用了内置 id | 换个名字 |
| `id xxx 已被内置形象占用` | 同上 | 换个名字 |
| `id xxx 和这次导入的另一个形象包重复` | 一次选了多个包，id 撞了 | 一次只导一个，或改 id |
| `name 缺失` | `name` 是空的，或者值全是空格 | 至少写 `{"zh":"名字"}` |
| `about 缺失` | 同上 | 至少写一句描述 |
| `entry 或 export 不合法` | `entry` 是绝对路径、含 `..`、或 `export` 是空字符串 | `entry` 写 `figure.js`，`export` 写函数名 |
| `model 路径不合法` | `model` 指向包外 | 改成包内相对路径，或删掉这个字段 |
| `thumb 路径不合法` | `thumb` 指向包外 | 改成包内相对路径 |
| `axes 里有不合法的一项："..."` | 轴的 id 不合规，或没有 name，或 options 是空的 | 看 `02` 文档 2.3 节 |
| `axes.xxx 里有不合法的选项："..."` | 选项 id 带横杠、有大写、超过 24 位 | 只留小写字母数字 |
| `presets 里有不合法的一项："..."` | preset 的 id 不合规 | 同上 |
| `presets.xxx 没有选 yyy 的选项` | 预设少给了某条轴 | 每条轴都要给一个选项 id |
| `vocab 应为数组` | 写成了对象或字符串 | 改成 `[...]` |
| `vocab 里有不合法的 id："..."` | 词的 id 不合规 | 全小写字母数字横杠 |
| `vocab.xxx.names.zh 应为数组` | 写成了字符串 | 改成 `["开心"]` |
| `vocab.xxx 的名字不合法："..."` | 名字含逗号、顿号、空格、`【】<>`，或太长，或为空 | 去掉这些字符 |
| `vocab 里 xxx 指了不止一个词` | **最常见的坑**。两个词用了同一个名字，或者某个别名正好等于另一个词的 id | 全局查重。注意：id 本身也参与查重，所以英文别名别写成跟 id 一样 |
| `vocab.xxx.about 缺失` | 这个词没写 `about` | 补一句"这个表情长什么样" |
| `vocab.xxx.seconds 应为正数` | 写了 0、负数、字符串 | 改成 `0.9` 这种 |
| `sounds 应为对象` | 写成了数组 | 没有就写 `{}` |
| `sounds 里的名字不合法："..."` | 音效名不是小写字母开头 | 改成 `meow` 这种 |
| `sounds.xxx.file 应为形象包里的文件` | 用了绝对路径或 `..` | 改相对路径 |
| `sounds.xxx.volume 应为 0–1` | 超范围 | 写成 `1` 或 `0.5` |
| `moves 应为数组` / `moves 最多 8 项` | 格式或数量不对 | 不用就删掉这个字段 |
| `moves 里有不合法的 id：...` | 用了 `left` `center` `right` `cursor` 或数字 | 换名字 |
| `needs 应为数组` | 写错类型 | 不用就删掉 |
| `这不是能读的 zip：...` | 文件损坏，或者压成了 rar/7z 只改了后缀 | 重新用「发送到 → 压缩文件夹」压 |
| `解开后超过 128 MB` | 包太大 | 压小图片。长边 512 就够 |
| `超过 128 MB` | 上传时就超了 | 同上 |
| `有一个路径不能用：...` | 文件名里有 `<>:"\|?*` 或控制字符 | 改名 |
| `上传的内容不完整` | 传输中断 | 重新导入 |

## 二、能导入，但清单上有黄色提示

这些不阻止导入，只是那一条不生效。

| 你看到的原文 | 意思 | 要不要管 |
|---|---|---|
| `vocab.xxx.kind 是 "xxx"，这一版不认识，这个词不给 bot 用` | `kind` 不是 `expression` 也不是 `motion` | 要管，改 `kind` |
| `sounds.xxx 的 yyy 不是这一版放得了的 .ogg、.mp3 或 .wav，这个声音不会响` | 音效格式不对 | 转成 mp3 或删掉 |
| `sounds.xxx.kind 是 "xxx"，这一版只认 move、touch、face、snore、talk，这个声音不会响` | 音效分类不对 | 改 `kind` |
| `sounds.xxx 的 yyy 不存在，这个声音不会响` | 文件没打进包 | 补文件，或删这一项 |
| `can.walk 是 "xxx"，这一版不认识，按会走处理` | 写了字符串 | 改成 `true` 或 `false` |
| `needs 里的 "xxx" 这一版不认识，不提供` | 只支持 `"windows"` | 删掉，或改成 `"windows"` |

### 2.1 这些错不用手改，点「一键修复清单」

工具第四步有个绿色按钮。它只改 `figure.json`，不动 `figure.js`，改之前会把原件
备份到 `projects\<id>\backup\figure-时间.json`。

| 检查出的原文 | 一键修复怎么处理 |
|---|---|
| `about 要有至少一个语言的描述` | 字符串自动包成 `{"zh":"..."}`。`name` 同理 |
| `词 xxx 的 kind 是 None，会被跳过` | 按 id 补成 `expression` 或 `motion` |
| `词 xxx 缺 about` | 补一句 `露出「开心」的表情` 占位，之后你可以自己改具体 |
| `词 xxx 的 seconds 必须是大于 0 的数字` | 表情补 `0.9`，动作补 `1.2` |
| `词 xxx 缺 names` | 把 `aliases`、`name`、字符串数组都收进 `names.zh` |
| 两个词用了同一个别名 | 保留前一个，删掉后面那个 |
| `manifest`、`api` 不是 `2` | 改成 `2` |
| `entry`、`export` 不对 | 改回 `figure.js`、`createMyPet` |

`pink`、`purple`、`call`、`ding` 这种词会被移出 `vocab`，列在「被移出」里。
原因：它们不是表情也不是动作。配色要走 `axes`，声音要走 `sounds`，
塞进 `vocab` 只会被跳过。移出去的词在备份文件里都还在。

它修不了的：图片缺失、`figure.js` 语法错、id 和别的包撞名。这三类只能自己改。

**它还会顺手同步表情图。** `raw` 里的 `face_happy.png`、`face_happy.webp` 会被复制成
`tex/face-happy.png`，模板只认带横杠的名字。
`face_surprise.png` 会自动对到 `surprised`。
`body.png` 不动，那是「设为主图」管的。

同步完还剩模板原样的表情图，检查时会提示。点「挪走模板占位表情」会把它们移到
`tex/_unused/`，不删，随时能拿回来。打包时会跳过 `_unused`。

## 三、导入成功，但桌面上不对

这一栏没有报错文字，只能靠现象判断。

### 3.1 完全看不见宠物

**最常见原因是 `figure.js` 运行时报错。**

Coopanion 只在第一帧报一次错，然后就不画了。
错误文字不会弹窗，你得去看日志：

```
D:\AIGJ\Coopanion\data\logs\core.log
```

搜 `figure` 或 `error`。

或者本地先测：

```
cd /d E:\AI\Coopanion的宠物制作工具\studio
node tools\test_pack.mjs ..\projects\<id>\pack
```

`FAIL` 开头的就是原因。

按可能性排：

| 可能 | 怎么确认 | 怎么改 |
|---|---|---|
| 导出名写错 | 测试输出 `没有导出 xxx()` | 让 `figure.json` 的 `export` 和 `figure.js` 的函数名一致 |
| 工厂不是函数 | 同上 | 检查 `export function` 有没有写 |
| 返回的对象缺方法 | 测试输出 `body 少了必须的方法` | 用模板的写法，别自己实现 |
| 图片路径不对 | 测试输出 `href=` 是空的 | 检查 `tex/body.png` 在不在 |
| 代码里 `innerHTML` 赋了非字符串 | 测试输出 `draw() 抛错` | 用 `setAttribute` 或模板写法 |

### 3.2 出现了，但是个白方块 / 黑方块

图片不透明。

确认方法：
```
用照片查看器打开 tex\body.png，看背景是格子还是白色。
```
或者命令行：
```
python -c "from PIL import Image; im=Image.open(r'projects\<id>\pack\tex\body.png'); print(im.mode, im.getpixel((0,0)))"
```
`(0, 0, 0, 0)` 才是透明。`(255, 255, 255, 255)` 就是白底。

改法：重新抠图存成透明 PNG。

### 3.3 宠物很小，或者偏到一边

图片里留白太多。程序按整张图缩放。

改法：裁掉多余的透明边，让主体贴住边缘。
工具点「设为主图」会自动居中，但不会裁掉透明留白。

### 3.4 脚悬空，或者陷进任务栏

图片底部有多余的透明区域，或者有阴影。

改法：裁掉底部所有内容，让脚底正好贴着图片最后一行像素。

### 3.5 做表情时变成另一只宠物

模板自带的三张示例表情没删。

```
pack\tex\face-happy.png
pack\tex\face-love.png
pack\tex\face-sleepy.png
```

它们画的是蓝色的模板小生物。
留着你的宠物一开心就变身。

改法：删掉，或覆盖成你自己的。

### 3.6 表情完全没变化

先看有没有图，再看代码。

**一、一张 `face-*.png` 都没有。**
改法：至少补 `face-happy.png`。文件要放在 `pack\tex\` 里，名字带横杠。

**二、有图，但代码取错了变量。**这是最常见的一种。

`figure.draw(petG, face, frame)` 的第二个参数 `face` 是**对象**，不是名字。
表情名在 `frame.face` 里。写成 `faceUrls[face]` 永远取不到，因为键是 `[object Object]`。

改法：换成 `faceUrls[frame.face]`。

**三、检查工具里的行为抽样。**
跑 `node tools\test_pack.mjs projects\<id>\pack`，看到这一行才算通：

```
ok   换表情会换图：body.png → face-happy.png
```

### 3.7 它不走动

**先分清楚是「不动」还是「走路像平移」。**

像平移，说明它在走，只是没换帧。放 `tex\walk-00.png`、`walk-01.png` 一串序列帧就有腿了。
检查工具里这一行：

```
ok   走路会换帧：walk-00.png / walk-01.png / walk-02.png
```

真的不动，看 `can.walk` 是不是 `false`：

```
打开 figure.json，找 "can": {"walk": true}
```

也可能它正在坐着或睡着。戳它一下试试。

### 3.8 坐下、睡觉还是站着

缺 `tex\sit.png` 或 `tex\sleep.png`。

改法：把坐姿图和睡姿图放进 `pack\tex\`，分别命名 `sit.png`、`sleep.png`。
素材原名是 `mode_sit.png` 也没关系，工具同步时会自动改名。

### 3.9 拖不动它

点击判定圆不对。默认是圆心 `(128,136)`、半径 `104`。

如果宠物画得偏上或偏下，圆没盖住它。

改法：改 `figure.js` 里的 `hits`：

```js
get hits() {
  return [[128, 136, 104]];
}
```

`[x, y, 半径]`，都在 256 的格子里。

### 3.10 说话时嘴不动

这是模板没做的功能，不是 bug。

要做口型，得在 `draw()` 里读 `frame.talk`（0 到 1 的音量）来换嘴的图。
属于进阶，`02` 文档里有 `frame` 各字段的说明。

## 四、工具本身报错

### 4.1 双击 `启动工具.bat` 一闪就没了

Python 没在 PATH 里，或者没装。

验证：
```
python --version
```
没有输出就是没装。

修：
- 装 Python 3.10 以上，装的时候勾「Add python.exe to PATH」。
- 或者手动跑：
```
cd /d E:\AI\Coopanion的宠物制作工具\studio
python server.py
```
这样报错会留在窗口里。

还有一个可能：窗口一闪就没了是因为端口全被占了。
工具从 8848 往上找空位，8848 到 8861 都被别人占着才会失败。
先关掉占端口的程序，或者重启电脑。

### 4.2 页面能开，但显示「接口未配置」

Key 没存进去，或者保存时接口请求失败。

点「保存并测速」，看红色提示里写什么。

| 提示 | 原因 |
|---|---|
| `连不上：URLError` | 地址写错，或者没联网，或者要挂代理 |
| `接口返回 401` | Key 不对或过期 |
| `接口返回 404` | 地址少了 `/v1`，或模型名不存在 |
| `接口返回 400` | 模型名不对，或者这个模型不支持 `chat/completions` |

地址的写法：写到 `/v1` 就行，工具会自己补 `/chat/completions`。

```
https://api.deepseek.com/v1
https://api.xxx.com/v1
```

### 4.3 AI 生成时提示「模型没给出能解析的 JSON」

工具现在会直接告诉你到底是哪一种，不用猜。三种：

| 提示原文 | 真正的原因 | 处理 |
|---|---|---|
| `模型返回了空内容` | 上游把这段描述拦掉了，一个字都没给 | 换说法。别写「小女孩」「幼童」「巴掌大的小孩」，改成「Q 版卡通角色」「Q 版人物」 |
| `模型拒了这次描述，不是格式问题` | 模型自己拒绝，后面会附它的原话 | 同上，换说法再点一次 |
| `JSON 不完整` | 输出被截断了 | 工具会自动砍掉尾巴救回来。救不回来就再点一次 |
| `模型没给出能用的词` | 它把词表写成了台词 | 工具会自动补 15 个标准词，包照样能用 |

最后一个会自动兜住。生成完看「改了什么」那一栏，能看到补了哪些词。

**还有一个副作用要知道：** 词表生成用的是一次请求。
如果模型只给了表情没给动作，工具会自动补 7 个标准动作：
走路、跑、坐下、睡觉、跳、招手、跳舞。

### 4.4 视频抽帧失败

| 提示 | 处理 |
|---|---|
| `没找到 ffmpeg` | 装 ffmpeg，或者在 `studio\server.py` 顶部改路径 |
| `视频超过 60 MB` | 先剪短，或者降低分辨率 |
| `抽帧失败：...` | 视频编码不常见。先用别的工具转成 mp4 |

### 4.5 「设为主图」后图没变化

如果你没装 Pillow，工具会直接把原图复制成 `tex\body.png`。
这种情况下尺寸不会变成 512×512，但也能用。

想让它自动居中缩放：
```
pip install pillow
```

### 4.6 打包成功，但 Coopanion 说找不到 figure.json

zip 里多套了一层文件夹。

正确的 zip 结构：

```
figure.json
figure.js
thumb.png
tex/body.png
```

错误的：

```
myproject/figure.json
myproject/figure.js
```

Coopanion 能往下找 3 层，但超过就会失败。
工具打出来的包结构是对的，手动压缩时要注意。

## 五、排查顺序

按这个顺序，别跳。

**第一步：跑加载测试。**

```
cd /d E:\AI\Coopanion的宠物制作工具\studio
node tools\test_pack.mjs ..\projects\<id>\pack
```

`FAIL` 就照它说的改。这一步能解决七成的"看不见宠物"。

**第二步：看配置。**

```
projects\<id>\pack\figure.json
```

对照 `02` 文档的必填字段表，逐个打勾。

**第三步：看图片。**

- 是不是透明 PNG。
- 尺寸是不是方图。
- 脚底有没有贴边。
- `tex\` 里有没有模板自带的示例图。

**第四步：看日志。**

```
D:\AIGJ\Coopanion\data\logs\core.log
```

搜 `error`、`figure`、`pack`。

**第五步：问 AI。**

用 `03` 文档里「卡住了，让它诊断」那条提示词。
记得把测试的完整输出贴给它。

## 六、一句话记住的规则

| 规则 | 一句话 |
|---|---|
| id | 全小写，数字横杠，别叫 coo |
| version | 永远写 2 |
| entry / export | `figure.js` / `createMyPet`，别改 |
| 别名 | 只写中文，不带标点 |
| 重名 | id 也算名字，所以英文别名等于 id 就死 |
| 图片 | 透明、方图、脚贴底 |
| 模板表情 | 换宠物后立刻删掉三张示例 |
| 代码 | 不改 |
| 验收 | 只信 `test_pack.mjs` 和桌面上真实的样子 |
