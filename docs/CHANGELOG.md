# 更新记录

版本号跟着形象包的 `version` 走。这个工具本身用 `1.x`。

## v1.1.0 · 2026-10-28

准备开源。同时把一次完整体检的 11 个问题修完。详见
[08-体检报告-2026-10](08-体检报告-2026-10.md)。

### 安全

- `/api/open` 不再能打开本机任意路径。只允许项目目录内
- 所有 POST 校验 `Host`、`Origin`、`Content-Type`。伪造 Host 返回 403
- 请求体上限 96 MB，超了返回 413
- API Key 从 `studio/ai-config.json` 挪到用户目录，支持 `PETSTUDIO_KEY` 环境变量

### 新增

- **预览页** `studio/web/preview.html`。站 / 走 / 坐 / 睡、表情、三色背景、音效试听
- **脸部表情生成** `studio/facegen.py`。一张全身图出一整套表情小图
- **环境体检** `/api/env` 加启动横幅。打印 Pillow / ffmpeg / node 三项
- 页面支持 `?id=xxx` 直达某个项目
- `start.sh`（macOS / Linux）
- 视频抽帧支持关闭抠图、指定容差

### 修好

- 视频抽出来的帧不进走路分区，走路还是站立图平移
- 视频帧带整个背景、尺寸 1280×720、不贴底边
- 没装 ffmpeg 时的报错等于没说，现在直接给安装命令
- 缺 Pillow 时一半功能静默降级，现在启动就说清楚
- 上传不验内容，垃圾 base64 能写进 `tex/`
- 清单校验补三条官方硬限制：2048 个文件、单文件 16 MB、清单 256 KB
- 保留 id 从只拦 `coo` 改成也拦 `whale`
- 项目列表每次请求都全量校验，加 mtime 指纹缓存后 45 ms 降到 4 ms

### 文档

- 新增 `功能说明.md`、`开发说明.md`、`INSTALL.md`
- `00-开始读我.md` 补环境要求一段
- `02-形象包格式规范` 补官方硬限制，新增第十二节：给整身图做表情
